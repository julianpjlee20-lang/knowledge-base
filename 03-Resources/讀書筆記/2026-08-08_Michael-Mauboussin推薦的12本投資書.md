# Michael Mauboussin 推薦的 12 本投資書

> 來源：Acquirer's Multiple〈Michael Mauboussin: 12 Books That Every Investor Should Read〉（2018-11）。原始文章列出從 Mauboussin 多場 writings/interviews/lectures 蒐集的書單，未附每本 commentary。
> 底下 ISBN / publisher / 出版日期 / 頁數 皆由 Amazon + Open Library 雙源驗證後收錄。

## 為什麼這個書單值得追蹤

Mauboussin 是 Counterpoint Global 的 Consilient Research head，Columbia 商學院兼任教授 30 年，書單橫跨**估值（valuation）／行為經濟（behavioral）／競爭策略（strategy）／歷史（market history）**。這四個支柱就是他自己 Consilient Observer 研究報告的骨架。

讀書策略建議：
1. **估值與投資流程** → 從 #1 Security Analysis + #8 Damodaran on Valuation + #11 Random Walk 開始打底
2. **行為偏誤** → #3 Thinking Fast and Slow + #7 Nudge + #10 Choices Values and Frames 形成「Kahneman/Thaler/Tversky 三部曲」
3. **競爭與護城河** → #12 Competition Demystified（Greenwald 是 Mauboussin 多次引用的對象）
4. **Buffett 文化** → #2 Snowball + #5 Dear Chairman + #1 Security Analysis foreword 由 Buffett 寫
