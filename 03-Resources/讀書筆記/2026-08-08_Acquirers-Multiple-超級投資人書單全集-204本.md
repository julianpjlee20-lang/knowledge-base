# Acquirer's Multiple 超級投資人書單全集 — 204 本

> 來源：Acquirer's Multiple 整理的 14 篇文章（2018/08–11），含 12 位超級投資人書單 + Acquirer's Multiple 自選 Top 50 + Columbia University Reading List。
> 所有 204 本書的 Amazon product page 完整快照 + Open Library 補強 metadata 已存到 `/opt/data/research/mauboussin-booklist/`。

## 為什麼這個書單值得追蹤

Acquirer's Multiple 從每位投資人的 writings / interviews / lectures / shareholder letters 蒐集書單，反映**實際影響他們決策**的閱讀，不只是書評網站票選。書單跨度橫跨：

- **估值與證券分析**：Graham/Dodd/Damodaran/Klarman 的 Security Analysis 傳統
- **行為經濟與偏誤**：Kahneman/Thaler/Taleb 三巨頭
- **市場歷史與泡沫**：Bernstein/Galbraith/Mackay 的跨世代經典
- **競爭策略與護城河**：Greenwald/Porter 的 framework
- **Buffett 生態系**：Munger/Snowball/Essays/Dear Chairman 形成完整拼圖
