# YAML 控制 NotebookLM 簡報風格

**來源：** Brian C. (@brianciou) Substack

## 核心概念
用 YAML 結構化指令精確控制 NotebookLM 生成的簡報風格。

## 流程
1. Pinterest 找靈感（搜尋 "Poster" 或 "Landing page"）
2. AI 分析風格元素
3. 建構 YAML 風格說明書
4. 傳給 NotebookLM 生成
5. 迭代優化

## YAML 結構
- atmosphere（氛圍）
- color scheme（色彩方案）
- typography（字體系統）
- layout rules（版面規則）
- decorative elements（裝飾元素）

## 結論
這篇在教「如何精確跟 AI 溝通設計需求」，YAML 是橋樑連接想像與執行。
