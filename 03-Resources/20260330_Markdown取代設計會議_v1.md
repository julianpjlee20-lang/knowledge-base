# A Markdown File Just Replaced Your Most Expensive Design Meeting

**來源：** YouTube - AI News & Strategy Daily (Nate B Jones)
**影片：** https://youtu.be/CDClFY-R0dI

## 關鍵心得

1. **設計 Markdown 化**：用文字描述設計spec，AI 自動生成 UI
2. **MCP 是標準化接口**：讓各種工具串接更簡單（Creative Tools 的 USB 插槽）
3. **可程式化 > 純生成**：可控性更強（Remotion vs Sora/Runway）
4. **門檻低但天花板高**：人人可上手，但要做得頂尖還是需要功力

## 重點工具
- Google Stitch：語音即時轉 UI
- Remotion：影片變程式碼
- Blender MCP：用自然語言控制 3D 建模
