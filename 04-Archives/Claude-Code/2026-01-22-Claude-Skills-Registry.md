# Claude Skills Registry - claude-plugins.dev

## 資源連結
- **網站**: https://claude-plugins.dev/skills
- **說明**: Discover and install Agent Skills for Claude, Cursor, OpenCode, Codex, and other AI coding assistants

## 主要功能
- 自動索引 GitHub 上所有公開的 Claude Skills
- 支援快速搜尋和安裝
- 開源且社群維護

## 熱門 Skills 類別

### Backend Development
- **Backend Architecture Patterns** - Clean Architecture, Hexagonal Architecture, DDD
- **Software Architecture** - ReactJS, NextJS, NodeJS, Express, GraphQL, Go, Python

### Frontend Development  
- **Frontend Design** - 高品質前端 UI 設計，避免 generic AI aesthetics

### Prompt Engineering
- **Advanced Prompt Engineering** - 最大化 LLM 效能、可靠性和可控性

### 文件處理
- **xlsx** - Excel 試算表處理
- **pptx** - PowerPoint 簡報製作
- **docx** - Word 文件處理

## 安裝方式

```bash
# 安裝特定 skill
npx ai-agent-skills install <username>/<repo>

# 範例：安裝 backend skills
npx ai-agent-skills install alirezarezvani/claude-skills/engineering-team/senior-backend
```
