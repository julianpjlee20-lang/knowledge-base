# Claude.md Best Practices

## 什麼是 claude.md

Claude Code 的專案設定檔，用於自訂 Claude 在特定專案中的行為。內容會自動載入為 system prompt。

## 檔案層級

| 位置 | 作用範圍 |
|-----|---------| 
| `~/.claude/CLAUDE.md` | 全域設定 |
| `專案根目錄/CLAUDE.md` | 專案專用 |
| `子目錄/CLAUDE.md` | 子目錄專用 |

---

## 學習筆記

### 2025-01-22 21:35
所有 md file 應該歸檔於 docs 文件夾，而非隨意產生在各個資料夾內

### 2025-01-22 21:36
用 XML tags 包裝指令區塊，讓 Claude 更容易解析

唯一追蹤進度的文件請放在 `docs/dev-progress.md`，不要隨意產生文件。
