# S01 規劃期 - 採購發包

回到 [[00-八宅總覽]]　|　← [[S00-建照]]　|　→ [[S03-報開工]]

**時程**：M01-M05 (2025/06~10，5 個月)　**負責人**：普（執行）+ 婉琳（審核）+ 老闆（核准）

> 注意：本階段為「全案採發基準建立」，預算書定稿後續變更皆以此為基準。

## 流程步驟

1. 數量計算（含未辦事項）— 普
2. 擬定採發預算（分項：假設/結構/水電/裝修/機電）— 普
3. 主要分包詢比價（每分項 ≥3 家）— 普
4. 比價表送婉琳審核 → 老闆簽核（>20 萬）
5. 分包合約簽訂 → 婉琳歸檔
6. 建立廠商台帳 — 婉琳

## 採購/付款節點

- 採發預算書定稿 → 老闆核准（M05 前）
- 比價表 → 婉琳審核 → 老闆簽核
- 分包合約簽訂 → 廠商台帳建立
