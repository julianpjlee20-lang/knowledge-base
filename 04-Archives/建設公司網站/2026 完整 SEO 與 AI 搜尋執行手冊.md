# 第一章：核心概念與演變

## 1.1 SEO 的本質變化

### 傳統 SEO vs 現代 AI 搜尋

|時代|目標|成功指標|
|---|---|---|
|**傳統 SEO**|排名 → 點擊 → 流量 → 收益|藍色連結排名|
|**AI 搜尋時代**|排名 → 影響 AI 回應 → 品牌曝光|品牌出現在生成內容中|

### 為什麼傳統 SEO 仍然重要？

**RAG（Retrieval Augmented Generation）原理：**

```
使用者查詢 AI 平台
      ↓
AI 判斷：已知答案？
      ↓
   ┌──否──┐
   ↓      ↓
靜態訓練   搜尋網路
資料回答   取得來源
           ↓
      參考排名靠前的結果
           ↓
      生成增強回應
```

> **關鍵洞察**：AI 平台搜尋網路時，會優先參考 Google/Bing 排名靠前的結果，所以傳統 SEO 排名直接影響 AI 生成內容。

## 1.2 現代 SEO 公式

```
SEO 成功 = 傳統 SEO（80%）+ AI 優化新變數（20%）
```

### 傳統 SEO（80%）- 第一方信號

- 技術 SEO
- On-Page 優化
- 內容品質
- 網站架構
- 內部連結

### AI 優化新變數（20%）- 第三方信號

- 多平台評論
- 品牌情感（Sentiment）
- 無連結品牌提及
- 新聞稿敘事控制
- Listicle 曝光
- AI 品牌知識

# 第三章：網站技術審計

## 3.1 Screaming Frog 爬取設定

### API 連接（重要！）

```
必須連接：
✅ Google Analytics 4
✅ Google Search Console
✅ Ahrefs / SEMrush
⬜ PageSpeed Insights（可選）
```

### 爬取後優先檢查項目

|優先級|檢查項目|篩選方式|行動|
|---|---|---|---|
|🔴|非索引頁面有反向連結|Indexability = Non-Indexable + RD > 0|301 重定向|
|🔴|404 頁面有反向連結|Status Code = 404 + RD > 0|301 重定向|
|🔴|點擊深度 > 3|Crawl Depth > 3|調整架構|
|🟡|無流量無曝光無連結頁面|Clicks = 0 + Impressions = 0 + RD = 0|考慮刪除/整合|
|🟡|字數過多（膨脹）|Word Count > 競爭對手中位數 2 倍|精簡內容|
|🟡|字數過少（單薄）|Word Count < 100|擴充或刪除|
|🟢|內部連結 < 5|Unique Inlinks < 5|增加內部連結|

## 3.2 技術 SEO 檢查清單

# 第四章：關鍵字研究與群集規劃

## 4.1 從 GSC 提取關鍵字

### 步驟流程

```
1. GSC → 成效 → 篩選商業意圖關鍵字
                    ↓
2. 選擇重要頁面 → 匯出該頁面所有關鍵字（最多 1,000）
                    ↓
3. 分類：同頁變體 vs 需要新頁面
                    ↓
4. 規劃關鍵字群集（5-10 個支援頁面）
```

### 商業意圖關鍵字篩選

使用 Regex 篩選器排除非商業查詢，優先提取：

- 產品/服務相關
- 比較類（vs、比較）
- 最佳類（best、推薦）
- 價格類（價格、費用、多少錢）

## 4.2 關鍵字分類邏輯

### 判斷方法：SERP 測試

```
1. 搜尋主關鍵字，記錄前 10 名
2. 搜尋變體關鍵字，比較前 10 名
3. 結果差異大 → 需要新頁面
   結果相似 → 同頁處理
```

### 分類表格範例

|關鍵字|類型|處理方式|
|---|---|---|
|AI search visibility tools|主關鍵字|核心頁面|
|AI search monitoring tools|變體|加入主頁面|
|AI search platforms|變體|加入主頁面|
|Best AEO tracking tools|新頁面|建立專屬頁面|
|ChatGPT visibility tools|新頁面|建立專屬頁面|

## 4.3 群集規劃範例

```
核心頁面：Best AI Search Visibility Tools
    │
    ├── Best AEO Tracking Tools
    ├── Best AI Mode Rank Tracking Tools
    ├── Best Google AI Overview Tools
    ├── Best ChatGPT Visibility Tools
    ├── Best Claude Visibility Tools
    ├── Best Perplexity Tracking Tools
    ├── Best Grok Tracking Tools
    └── Best Meta AI Tracking Tools

目標：每個核心頁面有 5-10 個支援頁面
```

# 第六章：內容策略與品質

## 6.1 滿足搜尋意圖

### 意圖類型與內容格式

|意圖類型|典型關鍵字|建議格式|
|---|---|---|
|資訊型|什麼是、如何、為什麼|教學文、指南|
|導航型|品牌名、產品名|官方頁面|
|商業型|最佳、比較、評價|Listicle、比較表|
|交易型|購買、價格、優惠|產品頁、服務頁|

### SERP 分析流程

```
1. 搜尋目標關鍵字
2. 分析前 10 名的內容類型
3. 識別共同格式（Listicle? 教學? 比較?）
4. 採用已驗證的格式
5. 找到差異化角度
```

## 6.2 內容差異化策略

### 差異化槓桿

|槓桿|說明|範例|
|---|---|---|
|**努力**|投入更多時間/資源|實際購買並閱讀所有推薦書籍|
|**數據**|原創研究/案例|自己做 CMS SEO 效能研究|
|**深度**|更詳細的分析|每個產品都有完整評測|
|**體驗**|第一手使用經驗|實際使用所有推薦工具|
|**視角**|獨特觀點/角度|從特定族群角度出發|

### 內容品質標準（對應 Google 指南）

|特質|問題|標準|
|---|---|---|
|**Helpful**|是否完整回答搜尋意圖？|使用者不需返回 Google|
|**Original**|是否帶來新資訊？|有獨特數據/觀點/經驗|
|**Accurate**|資訊是否正確？|引用可信來源|
|**Safe**|是否安全可信？|無惡意內容|
|**Effort**|是否明顯投入努力？|表面即可看出|

## 6.3 可讀性優化

### 格式原則

```
✅ 正確做法：
- 短段落（2-3 句）
- 短句子
- 多標題分段
- 黑字白底
- 有價值的視覺素材
- 表格整理複雜資訊

❌ 避免做法：
- 大段落（5+ 句）
- 複雜長句
- 缺乏標題
- 彩色背景
- 裝飾性圖片
- 過多廣告干擾
```

## 6.4 AI 內容使用原則

|競爭程度|AI 內容使用建議|
|---|---|
|低競爭|可較多使用，人工編輯|
|中競爭|AI 草稿 + 人工大幅編輯 + 連結支援|
|高競爭|建議人工撰寫或專家審核|

### AI 內容例外

當內容**資訊本身是獨特的**時，AI 撰寫是可接受的：

- 原創研究數據分析
- 獨家案例研究
- 個人經驗分享

> 關鍵不是「誰寫的」，而是「帶來什麼新資訊」

```

├── 更新日期（如有）

```

## 7.4 引用與來源

### 引用原則

```
✅ 連結到權威來源：
- 政府網站（.gov）
- 學術機構（.edu）
- 權威媒體
- 官方文件
- 學術研究

❌ 避免引用：
- 來源不明的網站
- 競爭對手
- 低品質內容農場
```

### 評論管理

```
✅ 最佳實踐：
- 回覆每一則評論（正面和負面）
- 回覆中自然提及服務/地區
- 感謝具體內容
- 負評：道歉、提供解決方案、邀請私下聯繫

❌ 避免：
- 假評論
- 批量購買評論
- 忽略負評
```

# 第十章：第三方信號與連結建設

## 10.1 反向連結類型分析

|類型|說明|價值|
|---|---|---|
|**Editorial**|國家級媒體（Forbes、HuffPost）|最高|
|**Localized**|當地贊助、獎學金、活動|高（本地 SEO）|
|**Directories**|產業目錄、商業目錄|中|
|**Press Releases**|新聞稿分發|中（品牌敘事）|

## 10.2 新聞稿策略

### 新聞稿的真正價值

> 不是為了連結，而是為了**控制品牌敘事**和**建立正面情感**

### 有效的新聞稿模板

|類型|範例|
|---|---|
|獎項|`[品牌] 榮獲 [獎項名稱]`|
|動態|`[品牌] 於 [地點] 開設新據點`|
|成果|`[品牌] 成功完成 [專案/交易]`|
|里程碑|`[品牌] 累積服務 [數量] 客戶`|

## 10.3 Listicle 曝光

### 為什麼重要？

- AI 平台常引用「最佳 X」類型文章
- 即使沒有連結，品牌提及也有價值
- 建立品牌與主題的關聯

### 執行方法

```
1. 搜尋「最佳 [你的服務] [地區]」
2. 列出排名靠前的 Listicle
3. 聯繫作者/編輯申請收錄
4. 提供獨特賣點和資料
```

## 10.4 連結建設策略

### 內部連結優化

```
1. 從高反向連結頁面加內部連結
2. 確保重要頁面有 5+ 內部連結
3. 內部錨點文字多樣化
4. 對標競爭對手的內部連結數量
```

### 外部連結獲取

|方法|難度|價值|
|---|---|---|
|內容行銷（Epic Content）|中|高|
|數據研究/報告|高|最高|
|客座文章|低|中|
|HARO/記者查詢|中|高|
|壞連結替換|中|中|
|資源頁面|低|中|
|當地贊助|低|中（本地）|

## 11.3 單頁 SEO 檢查清單

### 發布前檢查

```
基礎 On-Page：
□ 關鍵字在 URL
□ 關鍵字在 Title（60 字元內）
□ 關鍵字在 Meta Description（155 字元內）
□ 關鍵字在 H1
□ 關鍵字在第一句
□ H1 在首屏之上
□ 標題結構正確（H1→H2→H3）

內容品質：
□ 字數在合理範圍
□ 文法分數 95+
□ 原創度 > 50%
□ 引用可信來源
□ 有價值的視覺素材

內部連結：
□ 至少 5 個內部連結
□ 錨點文字多樣化
□ 連結到相關頁面

技術：
□ 無 noindex
□ Canonical 正確
□ Schema 標記（如適用）
□ 圖片有 alt 屬性
□ 圖片已壓縮

E-E-A-T：
□ 作者資訊顯示
□ 發布日期顯示
□ 來源有引用
```

## 結語：SEO 成功的關鍵心態

### 1. 品質優先於數量

> 「讓你的內容好到競爭對手看了就想放棄這個關鍵字」

### 2. 長期思維

> 今天的領先指標 = 6-12 個月後的滯後指標

### 3. 使用者至上

> 滿足使用者意圖，搜尋引擎排名自然會來

### 4. 持續迭代

> SEO 沒有「完成」的一天，只有持續優化

### 5. 數據驅動

> 用數據做決策，不要憑感覺
