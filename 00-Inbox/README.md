# 00-Inbox

## Rules

- 不確定分類時先放這裡，並標 `status: needs-triage`。
- AI draft 需要 human review 後才能移入 `01-Projects/`、`02-Areas/` 或 `03-Resources/`。
- Dropbox 原始資料只建立摘要與來源連結，不在這裡塞大型原檔。
