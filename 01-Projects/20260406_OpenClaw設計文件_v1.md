# 公司 OpenClaw 共用系統設計

## 目標
- 全公司共享同一個 AI 助手
- 每個同事有獨立的對話 Session（資料隔離）
- 共享技能/知識庫

## 兩種模式

### 模式 A：單一代理 + 多 Session（推薦）

共用一個 agent，透過 Discord/Telegram DM 區分用戶：

```json
{
  "agents": {
    "list": [
      {
        "id": "company",
        "name": "公司助手",
        "workspace": "~/.openclaw/workspace-company"
      }
    ]
  },
  "bindings": [
    {
      "agentId": "company",
      "match": {
        "channel": "discord",
        "accountId": "default"
      }
    }
  ],
  "channels": {
    "discord": {
      "groupPolicy": "allowlist",
      "allowFrom": [
        "USER_ID_1",
        "USER_ID_2",
        "USER_ID_3"
      ]
    }
  }
}
```

**優點**：
- 單一維護點
- 共享技能/記憶
- Session 自動隔離

---

### 模式 B：多代理 + 共享技能

每個部門或功能獨立的 agent：

```json
{
  "agents": {
    "list": [
      { "id": "support", "name": "客服" },
      { "id": "coding", "name": "工程師" },
      { "id": "hr", "name": "人資" }
    ]
  },
  "bindings": [
    { "agentId": "support", "match": { "channel": "discord", "peer": { "id": "SUPPORT_CHANNEL_ID" } } },
    { "agentId": "coding", "match": { "channel": "discord", "peer": { "id": "CODING_CHANNEL_ID" } } }
  ]
}
```

## 共享技能設定

### 全域共享技能
放在 `~/.openclaw/skills/`，所有 agent 都能用：

```
~/.openclaw/skills/
├── company-knowledge/    # 公司知識庫
│   └── SKILL.md
├── slack/               # 整合 Slack
│   └── SKILL.md
└── weather/            # 天氣查詢
    └── SKILL.md
```

### 建立公司助手 workspace
```bash
mkdir -p ~/.openclaw/workspace-company/skills
# 放共享技能連結或副本
```

---

## 設定檔範例（單代理模式）

```json5
{
  agents: {
    list: [
      {
        id: "company",
        name: "公司助手",
        workspace: "~/.openclaw/workspace-company",
        model: "minimax-portal/MiniMax-M2.5"
      }
    ]
  },
  
  bindings: [
    { agentId: "company", match: { channel: "discord" } }
  ],
  
  channels: {
    discord: {
      groupPolicy: "allowlist",
      allowFrom: [
        "1467853868988633088"  // 加入允許的用戶 ID
      ],
      streaming: "partial"
    }
  }
}
```

## 下一步

1. **確認用戶 ID** - 在 Discord 開啟 Developer Mode，右鍵取得
2. **建立 workspace** - `openclaw agents add company`
3. **設定技能** - 放入共享技能
4. **設定 allowFrom** - 加入公司成員
