# GitHub Issue Triage Skill

Use this skill to automatically triage new GitHub issues.

## Setup

1. Install GitHub CLI:
```bash
brew install gh
```

2. Authenticate:
```bash
gh auth login
```

## Usage

### List recent issues
```bash
gh issue list --owner <org> --repo <repo> --state open --limit 10
```

### View single issue
```bash
gh issue view <issue-number> --owner <org> --repo <repo>
```

### Triage workflow (with OpenClaw)

1. Detect new issues:
```bash
gh issue list --owner <owner> --repo <repo> --state open --limit 5 --json "number,title,labels,author,createdAt"
```

2. Analyze with LLM (provide issue content):
```
Please analyze this GitHub issue and suggest:
- Category (bug/feature/question)
- Priority (low/medium/high)
- Suggested labels
- Which team member should handle it

Issue: <title>
Description: <body>
```

3. Send notification to team (via Discord/Telegram)

## Automation with Cron

Add to OpenClaw cron for periodic checks:

```json
{
  "schedule": { "kind": "cron", "expr": "0 9 * * 1-5" },
  "payload": { "kind": "agentTurn", "message": "Run GitHub issue triage for repo X" }
}
```

## Scripts

- `issue_triage.sh` - Basic keyword-based triage
- `issue_notify.py` - Send triage results to Discord
