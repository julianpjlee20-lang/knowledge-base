# 京都附近單次健身房 / Visitor Gym 候選

用途：日本旅行期間在京都臨時訓練，不辦月會籍。  
基準：尚未提供京都住宿地址，因此先以 **京都站 / 四條烏丸 / 河原町三條** 為主要活動區判斷。若之後補京都飯店，再重排步行距離。

## 最推薦

### 1. Gold's Gym 京都烏丸

- 類型：最適合正式重訓；器材完整，品牌穩。
- 單次：**Visitor 1回 2,860円，5小時內**。
- 營業：月～土 7:00–23:00；日 7:00–21:00；祝日依星期；第2月休館。
- 地址：京都府京都市中京区烏丸通蛸薬師上ル七観音635番地 からすまビル2F。
- 交通：四條 / 烏丸、烏丸御池附近；如果住四條烏丸最方便。
- 電話：075-257-7171。
- 官方頁：https://www.goldsgym.jp/shop/26110
- 料金頁：https://www.goldsgym.jp/shop/26110/membership
- 導航：https://www.google.com/maps/search/?api=1&query=35.006657270537524,135.75824675815406

### 2. Gold's Gym 京都二条

- 類型：正式重訓；JR 二条站旁，從京都站搭 JR 約 6 分到二条後很近。
- 單次：**Visitor 1回 2,860円，7:00–23:00 間 5小時內**。
- 營業：24小時；但日 21:00～一 7:00 關閉；第3月休館。
- 地址：京都府京都市中京区西ノ京東栂尾町3 JR二条駅NKビル2F。
- 電話：075-803-2626。
- 官方頁：https://www.goldsgym.jp/shop/26100
- 海外旅客說明：https://www.goldsgym.jp/news/29874
- 導航：https://www.google.com/maps/search/?api=1&query=35.01129077052657,135.74102625815746

### 3. GYM valor PLAYPARK / 24GYM KYOTO

- 類型：河原町三條附近 24h 小型 gym，對外國旅客有英文頁與 one-time use。
- 單次：**1 day pass 3,300円，首次入館起 24 小時內**。
- 其他短期：1 week pass 7,480円；2 week pass 11,000円。
- 營業：24時間365日無休。
- 地址：京都市中京区下丸屋町407-2。
- 適合：住河原町 / 京都市役所前 / 三條附近，想不受時間限制訓練。
- 注意：需線上註冊與 app / Bluetooth 開門；官方頁評論區也有少數入館 app 問題抱怨，出發前建議先完成註冊。
- 英文旅客頁：https://valor-kyoto.com/en/
- 官方 gym 頁：https://valor-kyoto.com/gym/
- 導航：https://www.google.com/maps/search/?api=1&query=35.01066,135.768679

## 京都站附近備選

### 4. Anytime Fitness 京都駅前店

- 類型：24h 連鎖 gym；非會員可用「1日體驗」。
- 單次 / 體驗：**1日体験 3,000円**，每人限一次。
- 可用時間：staff hour 內 **10:00–19:00**。
- 持物：身分證、訓練服、訓練鞋；館內土足利用。
- 地址：京都府京都市下京区七条通河原町西入材木町470 1F。
- 電話：075-744-6692。
- 官方頁：https://www.anytimefitness.co.jp/kyotoekimae/

## 便宜但較像公營 / 輕訓練

### 5. 京都市中央青少年活動センター トレーニングルーム

- 類型：公營 / 青少年中心健身房；不是高階重訓場，但在四條烏丸 / 烏丸御池很方便。
- 單次：一般 **620円 / 次**；青少年 310円。
- 使用時間：平日・土 10:00–21:00；日・祝 10:00–18:00。
- 注意：**必須先上トレーニングルームガイダンス並註冊，且需事前預約**；不適合只想當天直接進場的人。
- 地址：京都市中京区東洞院通六角下る御射山町262。
- 官方設備頁：https://ys-kyoto.org/chuo/room/
- ガイダンス頁：https://ys-kyoto.org/chuo/581/

### 6. 京都市地域体育館 / 運動公園 Training Room

- 類型：市營運動設施，價格便宜，但地點分散、器材偏基礎。
- 費用：官方列部分設施 **450円 / 次**，部分設施 **460円 / 次**；依設施不同。
- 時間：部分設施 10:00–20:00（受付至19:00）或 9:00–21:00（受付至20:00）。
- 注意：出發前要選定設施並確認是否需要講習 / 初次登錄。
- 官方頁：https://www.kyoto-taiikukan.com/training-room

## 是否有「不用登記會員、隨到隨用」？

嚴格來說，京都幾乎沒有完全「不用任何登記、直接刷現金進去」的健身房。最接近的是 **Gold's Gym Visitor**：不用辦月會籍，但進場仍需帶護照/在留卡、填寫訪客資料、提供日本住宿地址，並穿室內鞋。

- **最接近隨到隨用：Gold's Gym 京都烏丸 / 京都二条**  
  Visitor 1日券 2,860円 / 5小時；現場辦訪客使用，非月會員。建議避開閉館/休館時段，帶護照、住宿地址、室內鞋。
- **不是隨到隨用：GYM valor PLAYPARK**  
  有 1 day pass，但官方寫明需線上註冊、下載 app、用 Bluetooth 開門。
- **不是隨到隨用：Anytime 京都駅前店**  
  是 1日体験 3,000円，但限 staff hour 10:00–19:00，需身分證與現場手續。
- **不是隨到隨用：京都市中央青少年活動センター / 市營 training room**  
  便宜，但通常需事前講習 / ガイダンス / 初次登錄。

## 我的排序

1. 想正式練、又不辦會員：**Gold's Gym 京都烏丸**。
2. 住京都站、願意搭一站 JR：**Gold's Gym 京都二条**。
3. 住河原町 / 三條、可接受線上註冊 app：**GYM valor PLAYPARK**。
4. 只在京都站附近、可接受 staff hour 與體驗手續：**Anytime 京都駅前店 1日体験**。
5. 省錢但能接受預約講習：**中央青少年活動センター** 或市營 training room。
