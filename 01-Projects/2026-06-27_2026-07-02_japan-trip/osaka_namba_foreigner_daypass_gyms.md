# RITA HOTEL NAMBA 附近：健身房重新找尋

更新：2026-06-22  
住宿起點：**RITA HOTEL NAMBA**（大阪市西成区中開1-3-12；34.651546, 135.494003）

> 本版已依使用者提供的 RITA 出發距離重估；舊版用到難波舊飯店座標的 10–17 分步行距離已作廢。

## 結論

如果目標是「飯店附近可實際訓練」＋「旅客 / 外國人單次使用」，排序如下：

1. **URBAN FIT24 難波店** — 最近，但需確認台灣護照 visitor 可否使用
   - RITA 出發：約 **1.79 km / 22 分**
   - 地址：大阪府大阪市浪速区元町1丁目11-16 ヴォンジョルノ難波 1階
   - 單次使用：ビジター利用 **2,530円**，可用時間 **11:00–21:00**
   - 3 日券：**3daysプラン 6,160円**，官方說明為「3日間24時間、施設をご利用頂けるプランです。」
   - 租借：ビジターレンタル（衣服上下、毛巾、鞋）990円；3days 用ビジターレンタル 2,970円
   - 訂購方式研究（官網實查）：價格頁沒有 3days 專用線上購買按鈕；難波店頁面的「来店予約」與「体験入会」按鈕在 HTML 中被註解掉；可點的「WEB入会」導向一般會員入會流程，需本人確認 / 顔写真 / 静脈認証，並非 3days 短期券。FAQ 只明確寫 1 日都度利用可在 11:00–21:00 受付，出示身分證明並都度付款。因此目前可驗證的 3days 購買方式是 **staff hour 到店櫃台辦理 / 開通**，不是線上預約購買。
   - 風險：官方有 visitor / 3days 價格，但 3days 頁面未單獨寫海外觀光客文件；FAQ 對 1日都度利用要求身分証明書。外國旅客實務上應帶護照，並在 11:00–21:00 到店櫃台處理。
   - 電話：06-7777-9424（スタッフ受付時間 11:00–21:00）
   - 官方料金頁：https://urbanfit.jp/price/namba/
   - 官方お問い合わせ：https://urbanfit.jp/entry2/contact.php?shop=namba
   - Google Maps：https://www.google.com/maps/search/?api=1&query=URBAN+FIT24+%E9%9B%A3%E6%B3%A2%E5%BA%97

2. **Gold's Gym 心斎橋大阪** — 最穩妥的外國人單次使用
   - RITA 出發：約 **2.94 km / 37 分**
   - 地址：大阪市中央区西心斎橋1丁目6-14 BIG STEP 6F
   - 單次使用：Visitor **1回 2,860円 / 5時間迄**
   - 外國人規則：官方明寫非日本籍需出示 **passport** 或外國人登錄證明，並可能影印。
   - 營業：ジム 月–土 7:00–23:30、日 9:00–22:00、祝 7:00–22:30；第2月曜休館，另有夏季 / 年末年始休館。
   - 官方頁：https://www.goldsgym.jp/shop/220817/membership
   - Google Maps：https://www.google.com/maps/search/?api=1&query=Gold%27s+Gym+%E5%BF%83%E6%96%8E%E6%A9%8B%E5%A4%A7%E9%98%AA

3. **LIFIX GYM 大阪難波 / 日本橋** — 旅客友善備選，但已超出飯店附近步行圈
   - RITA 出發：約 **3.44 km / 43 分**
   - 地址：大阪府大阪市中央区島之内2-17-13
   - 單次使用：ビジター利用 **1回 2,650円**；利用時間 **9:30–21:00**，最終受付 20:00
   - 旅客友善：官方英文文章寫 tourists / day pass / no membership required。
   - 官方頁：https://fitness.lifix.life/
   - 官方旅客文章：https://fitness.lifix.life/blog/3080/
   - Google Maps：https://www.google.com/maps/search/?api=1&query=LIFIX+GYM+%E5%A4%A7%E9%98%AA%E9%9B%A3%E6%B3%A2

4. **Koi-Fit24** — 外國旅客明確友善，但不適合同日臨時去
   - RITA 出發：約 **3.43 km / 43 分**
   - 地址：4-32-21 Minamihorie, Nishi-ku, Osaka
   - 1-Day Visitor Pass：**3,850円**
   - 條件：明確寫 international visitors / tattoos OK / street shoes allowed / 24/7 access；但需 **至少 24 小時前預約**，並透過 LINE 做 ID/passport verification。
   - 官方頁：https://24.koi-fit.com/assets/pages/visitor.html
   - Google Maps：https://www.google.com/maps/search/?api=1&query=Koi-Fit24+Osaka

## 附近但不列為優先的健身房

以下是以 RITA 3.5km 內重新掃描到的健身 / 運動設施，但目前不列為優先：

- **Park Gym**：OSM 顯示約 1.27km 直線附近；未找到明確 visitor / day pass 官方資訊，先不列為可用候選。
- **なんば温泉**：OSM 被標成 fitness centre，但更像溫浴 / 錢湯類型，不作重量訓練候選。
- **渥美ボクシングジム / 井岡ボクシングジム**：拳擊館，非一般自由重量 / 機械訓練優先。
- **東急スポーツオアシス / JOYFIT24 / Anytime Fitness / KONAMI Sports**：多為會員制或需分店規則確認；沒有比 URBAN FIT24 / Gold’s Gym 更適合旅客單次使用。
- **chocoZAP**：通常偏會員 app 制、輕量器材，不列為旅行重訓首選。

- 最近的 URBAN FIT24 會變成 **高槻店**，從京都四條大宮步行距離約 **26.36 km / 330 分**，完全不列入飯店附近。

## 不列為飯店附近

- **FiT24 城東古市店**：約 **12.68 km / 159 分**；不列為 RITA HOTEL NAMBA 附近。若只是想健身，改看 URBAN FIT24 / Gold’s Gym / LIFIX。

## 最終建議

- **只看距離**：URBAN FIT24 難波店。
- **看外國人單次使用確定性**：Gold’s Gym 心斎橋大阪。
- **想要英文旅客友善資訊**：LIFIX GYM 或 Koi-Fit24，但步行較遠；Koi-Fit24 需要提前 24 小時。
