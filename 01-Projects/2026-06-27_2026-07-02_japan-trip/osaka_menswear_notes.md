# 大阪男裝逛街紀錄：梅田 / 心齋橋

## 已記錄的重點區域

### Hankyu Men's Osaka / 阪急メンズ大阪（梅田）
- 性質：日本代表性的男士百貨，適合一次看高級設計師品牌、正裝、皮件、鞋履、香氛與男士保養。
- 地址區域：大阪市北区角田町7-10，梅田 / 大阪站商圈。
- 營業時間參考：多數櫃位為平日 11:00–20:00，週末 / 假日 10:00–20:00；實際以阪急男士館官方公告與當日店鋪頁為準。
- 適合目的：想快速看高級男裝、俐落剪裁、商務休閒與成熟質感品牌。
- 地圖定位：已加入 `itinerary_map.html`。

#### H THE TOKYO 大阪 / B1F（ssstein）
- 重點：**H THE TOKYO 有 ssstein 取扱**；ssstein 官方 STOCKIST 列出 H THE TOKYO，地址為阪急メンズ大阪 B1F。
- 地址：〒530-8350 大阪府大阪市北区角田町7-10 阪急メンズ大阪 B1F。
- 電話：06-6313-9909。
- 營業時間：平日 11:00–20:00；土日祝 10:00–20:00。
- 適合目的：看 ssstein 男裝、新作、褲裝 / outer；可與阪急男士館其他品牌一起排。
- 詳細整理：`osaka_h_the_tokyo_ssstein.md`。

### GRAND FRONT Osaka / グランフロント大阪（梅田）
- 性質：大型複合商場，有高級選品店、生活風格品牌與成熟質感男裝。
- 地址區域：大阪站北側，梅田商圈。
- 營業時間參考：物販多為 11:00–21:00；餐飲多為 11:00–23:00；各店與臨時營業以官方頁為準。
- 適合目的：比百貨更生活風格，可看 ESTNATION、BEAMS、戶外 / 機能 / 生活選物。
- 地圖定位：已加入 `itinerary_map.html`。

### JOURNAL STANDARD 難波店 / なんばCITY B1F
- 性質：日系休閒 / 選品 / Baycrews 系，男女裝；比百貨更日常，適合難波步行逛街。
- 地址：大阪府大阪市中央区難波5-1-60 なんばCITY 本館 B1F。
- 營業時間：11:00–21:00。
- 電話：Men's 06-6644-2415；Ladies 06-6644-2419。
- 備註：On 官方 dealer 搜尋也有出現，可順路看 On；但它是服飾選品店，不是跑鞋專門店。
- 地圖定位：已加入 `itinerary_map.html`。
- 詳細整理：`osaka_journal_standard_namba.md`。

### 心齋橋 / 美國村（Amerikamura）
- 性質：街區型商圈，偏潮流、古著、街頭、選物店。不是單一商場，店家營業時間差異大。
- 營業時間：需逐店確認；不可用商圈時間直接排定。
- 適合目的：找比較年輕、潮流、日系街頭或古著；若目標是「40歲俐落剪裁」，建議只挑特定店，不要漫無目的逛太久。
- 地圖定位：已加入 `itinerary_map.html`。

## 40歲男生：俐落剪裁 / 成熟乾淨感推薦品牌

### 首選：成熟、剪裁乾淨、好穿
1. **TOMORROWLAND MEN**
   - 風格：乾淨、成熟、都會感，外套、襯衫、針織、西褲都穩。
   - 適合：40歲想要不老氣但正式度夠的 smart casual。
   - 大阪可看：Hankyu Men's Osaka、Osaka Takashimaya、LUCUA 等。

2. **ESTNATION**
   - 風格：高級選品店，線條俐落、質感偏成熟。
   - 適合：襯衫、西裝外套、皮鞋、簡潔高級休閒。
   - 大阪可看：GRAND FRONT Osaka 南館 1F。

3. **UNITED ARROWS**
   - 風格：日本成熟男裝代表，剪裁、比例、材質穩定。
   - 適合：商務休閒、西裝外套、褲子、襯衫；不想太潮時很好買。
   - 大阪可看：梅田 / 心齋橋一帶店鋪需逐店確認。

4. **BEAMS F / Brilla per il gusto**
   - 風格：BEAMS 內偏成熟紳士線，義式剪裁、外套、襯衫、皮鞋感強。
   - 適合：想要更精緻、有品味但不過度正式。
   - 大阪可看：BEAMS 梅田等。

5. **EDIFICE**
   - 風格：法式 / 都會男裝，價格通常比高級百貨品牌更好入口。
   - 適合：俐落日常、乾淨襯衫、外套、褲裝。
   - 大阪可看：BAYCREW'S 系列店鋪，需逐店確認。

### 如果想買更高級 / 西裝剪裁
6. **RING JACKET**
   - 風格：大阪起家的高品質西裝品牌，剪裁與做工是重點。
   - 適合：想買真正像樣的西裝、外套、紳士單品。
   - 大阪可看：RING JACKET MEISTER 206 YODOYABASHI，11:00–20:00；部分店休日需注意。

7. **Theory Men**
   - 風格：極簡、修身、乾淨，商務休閒好搭。
   - 適合：不想花太多時間搭配，想要安全俐落。
   - 大阪可看：阪急梅田男裝等，需確認男裝櫃位營業。

### 日系質感但較休閒
8. **MARGARET HOWELL / MHL.**
   - 風格：自然、簡潔、乾淨，版型不緊但有質感。
   - 適合：成熟休閒、旅行穿搭。

9. **Graphpaper**
   - 風格：極簡、寬鬆但乾淨，偏設計感。
   - 適合：不想太正式，但要有質感與輪廓。

10. **nanamica / THE NORTH FACE PURPLE LABEL**
   - 風格：機能、乾淨、成熟戶外感。
   - 適合：旅行、休閒外套、襯衫、褲子。

## 最推薦逛法

### 如果只排 60–90 分鐘
Hankyu Men's Osaka：TOMORROWLAND MEN → BEAMS F / Brilla → Theory Men → 其他高級品牌。

### 如果排 2–3 小時
Hankyu Men's Osaka → GRAND FRONT Osaka（ESTNATION / BEAMS / 生活風格店）。

### 如果要順路心齋橋
心齋橋 / 美國村只挑已確認店家；不建議用「亂逛」方式找俐落剪裁，容易逛到偏年輕潮流或古著。

## 待查清單
- 之後若要正式加入行程，需逐店確認：營業時間、公休日、樓層、是否有男裝線、是否退稅。
- 特別需查：UNITED ARROWS 大阪 Men's Store、BEAMS 梅田、EDIFICE 大阪、Theory Men 梅田阪急店。
