## 一、核心主檔（Master）

### 1) `companies`（建設公司）
**何時用**：你的公司或集團內多家公司切帳。  
**範例紀錄**：
```json
{ "name": "山河建設", "uniform_no": "12345678", "default_currency": "TWD" }
```
**交叉**：`projects / bank_accounts / chart_of_accounts / parties / journals / AR/AP/loan_*` 都連到 `company_id`。

---

### 2) `bank_accounts`（銀行帳戶）
**何時用**：每家公司的活存、專戶、保證金戶等。  
**範例**：
```json
{ "company_id": 1, "bank_code": "012", "account_name": "工程週轉", "account_no": "123-4567890" }
```
**交叉**：`cash_bank_txns` 記錄收支；`loan_facilities` 指明貸款所屬帳戶；`journal_lines` 可標示走哪個帳戶。

---

### 3) `projects`（建案/專案）
**何時用**：每個建案獨立核算成本與收入。  
**範例**：
```json
{ "company_id": 1, "project_code": "SB01", "project_name": "松柏一號", "start_date": "2025-02-01" }
```
**交叉**：`journal_lines / AR / AP / contracts / progress_claims` 等多數明細可帶 `project_id`。

---

### 4) `chart_of_accounts`（會計科目）
**何時用**：總帳科目與是否可過帳、是否要求專案/對象。  
**範例**：
```json
{ "company_id": 1, "account_code": "5111", "account_name": "工程成本-材料", "account_type": "expense", "postable": true, "require_project": true }
```
**交叉**：`journal_lines.coa_id` 指向它；`cost_codes.default_coa_id` 可對應預設科目。

---

### 5) `cost_codes`（成本代碼）
**何時用**：工程成本細分（鋼筋、模板、機電…）供現場與財務一致核算。  
**範例**：
```json
{ "company_id": 1, "cost_code": "C-REBAR", "cost_name": "鋼筋", "category": "direct", "default_coa_id": 10 }
```
**交叉**：`journal_lines.cost_code_id`；也可延伸依成本代碼看損益。

---

### 6) `parties`（交易對象）
**何時用**：供應商、分包商、業主。  
**範例**：
```json
{ "company_id": 1, "party_type": "subcontractor", "name": "鵬程土木", "uniform_no": "87654321", "payment_terms": "月結45天", "wh_agent": true }
```
**交叉**：`AP/AR/contracts/cash_bank_txns/journal_lines` 都帶 `party_id`。

---

### 7) `tax_codes`（稅別/稅率）
**何時用**：進/銷項 5%、零稅率或免稅等。  
**範例**：
```json
{ "tax_code": "TX5", "tax_rate": 5.00, "scope": "output", "description": "銷項5%" }
```
**交叉**：`AR/AP/progress_claims/journal_lines` 的稅別欄位。

---

## 二、會計交易／憑證層（Ledger）

### 8) `journals`（分錄主檔）
**何時用**：每張傳票的抬頭（日期、來源模組、備註）。  
**範例**：
```json
{ "company_id": 1, "journal_date": "2025-03-15", "voucher_no": "JV-20250315-001", "source_module": "AP" }
```
**交叉**：`journal_lines` 明細必掛它；`cash_bank_txns/withholdings/loan_drawdowns/interest_accruals` 也可回寫 `journal_id`。

---

### 9) `journal_lines`（分錄明細）
**何時用**：所有會計分錄最終落點（借貸、金額、專案、對象、稅、銀行帳戶）。  
**範例（AP 認列材料）**：
```json
{ "coa": "5111 工程成本-材料", "debit": 1000000, "project": "松柏一號", "cost_code": "C-REBAR", "tax_code": "TX5" }
{ "coa": "2121 應付帳款-鵬程", "credit": 1050000, "party": "鵬程土木" }
```
> 備註：第一行借成本（未稅），第二行貸應付（含稅）。

**交叉**：用 `ref_type/ref_id` 指向來源單（如 `AP, ap_id`）方便追蹤。

---

### 10) `cash_bank_txns`（銀行/現金交易）
**何時用**：匯款、收款、票據入帳等，對帳用。  
**範例（付分包）**：
```json
{ "company_id": 1, "bank_account_id": 1, "txn_date": "2025-04-30", "direction": "out", "amount": 500000, "party_id": 5 }
```
**交叉**：與 `ar_ap_settlements` 連結做核銷；可回寫 `journal_id` 對應傳票。

---

## 三、AR / AP 與發票

### 11) `ar_invoices`（銷項／應收）
**何時用**：對業主請款開立發票（含保留款欄位）。  
**範例**：
```json
{ "company_id": 1, "project_id": 1, "customer_id": 9, "invoice_prefix": "AB", "invoice_no": "12345678",
  "issue_date": "2025-05-10", "untaxed_amount": 10000000, "tax_code": "TX5", "tax_amount": 500000,
  "total_amount": 10500000, "retainage_rate": 5.0 }
```
**交叉**：收款由 `ar_ap_settlements` 連結；分錄落 `journal_lines`（借 應收、貸 工程收入＋銷項稅額）。

---

### 12) `ap_bills`（進項／應付）
**何時用**：供應商/分包發票與到期應付。  
**範例**：
```json
{ "company_id": 1, "project_id": 1, "supplier_id": 5, "invoice_no": "B-2025-0321", "invoice_date": "2025-03-20",
  "untaxed_amount": 1000000, "tax_code": "TX5", "tax_amount": 50000, "total_amount": 1050000, "retainage_rate": 5.0 }
```
**交叉**：付款由 `ar_ap_settlements` 連結；分錄落 `journal_lines`（借 成本/進項稅額、貸 應付帳款）。

---

### 13) `ar_ap_settlements`（收付款核銷主檔）
**何時用**：把一筆收/付款與多張 AR 或 AP 做多對多核銷。  
**範例（對分包付款核銷）**：
```json
{ "company_id": 1, "direction": "ap_payment", "txn_id": 1001, "amount": 500000 }
```
**交叉**：對應到 `ar_settlement_links` 或 `ap_settlement_links`。

---

### 14) `ar_settlement_links`（核銷明細-應收）
**何時用**：把一筆收款分攤到多張 AR。  
**範例**：
```json
{ "settlement_id": 2001, "ar_id": 3009, "applied_amount": 300000 }
```

---

### 15) `ap_settlement_links`（核銷明細-應付）
**何時用**：把一筆付款分攤到多張 AP。  
**範例**：
```json
{ "settlement_id": 2002, "ap_id": 3150, "applied_amount": 500000 }
```

---

### 16) `withholdings`（扣繳／代扣代繳）
**何時用**：分包工程給付或租金等需扣繳時。  
**範例**：
```json
{ "company_id": 1, "party_id": 5, "category": "工程給付", "rate": 1.0, "base_amount": 500000, "tax_amount": 5000, "voucher_no": "WH-2025-0001" }
```
**交叉**：常跟 `ap_payment` 同時發生，分錄會借 應付帳款、貸 銀行與 應付代扣稅。

---

## 四、工程專屬（合約／請款／變更）

### 17) `contracts`（合約主檔）
**何時用**：主合約、分包合約、採購合約、售屋合約等條款與總價。  
**範例（分包）**：
```json
{ "company_id": 1, "project_id": 1, "contract_type": "subcontract", "counterparty_id": 5,
  "contract_no": "SUB-SB01-001", "total_amount": 20000000, "retainage_rate": 5.0 }
```
**交叉**：`progress_claims` 依合約期別請款；`change_orders` 調整合約總額；後續請款開 AP/AR 與分錄。

---

### 18) `progress_claims`（進度請款／驗收）
**何時用**：依期別對主約或分包請款（含保留款計提）。  
**範例（分包第 2 期）**：
```json
{ "contract_id": 10, "period_label": "2025-03", "claimed_amount": 1000000, "retainage_amount": 50000,
  "approved_amount": 980000, "tax_code": "TX5", "status": "approved" }
```
**交叉**：核准後可自動產生 `AP bill`（分包）或 `AR invoice`（對業主），並建立分錄。

---

### 19) `change_orders`（變更設計／追加減）
**何時用**：變更工程內容與金額。  
**範例**：
```json
{ "contract_id": 10, "reason": "增加地下室加固", "amount_delta": 2500000, "approved_date": "2025-04-10" }
```
**交叉**：回寫 `contracts.total_amount`；影響後續 `progress_claims` 可請款額與預算。

---

## 五、融資／借款

### 20) `loan_facilities`（借款主檔／授信）
**何時用**：建築融資或週轉金貸款的契約。  
**範例**：
```json
{ "company_id": 1, "bank_account_id": 1, "loan_type": "construction", "credit_limit": 150000000,
  "base_index": "TAIBOR", "spread_bps": 120, "start_date": "2025-02-15" }
```
**交叉**：`loan_drawdowns` 撥貸、`loan_schedules` 還款排程、`interest_accruals` 利息計提；分錄進 `journal_lines`。

---

### 21) `loan_drawdowns`（動撥／撥貸）
**何時用**：實際動用授信資金。  
**範例**：
```json
{ "loan_id": 1, "draw_date": "2025-03-05", "amount": 20000000, "purpose": "支付地價款" }
```
**交叉**：常同步建傳票（借 銀行存款、貸 借款）。

---

### 22) `loan_schedules`（攤還排程）
**何時用**：本金/利息每期應還資訊。  
**範例**：
```json
{ "loan_id": 1, "period_no": 1, "start_date": "2025-03-01", "end_date": "2025-03-31",
  "due_principal": 0, "due_interest": 120000, "rate_annual_pct": 3.2 }
```
**交叉**：到期時據此開立付款/分錄；可連 `cash_bank_txns` 與 `journals`。

---

### 23) `interest_accruals`（利息計提）
**何時用**：月底計提應付利息（未付）。  
**範例**：
```json
{ "loan_id": 1, "period_start": "2025-03-01", "period_end": "2025-03-31", "accrual_amount": 120000 }
```
**交叉**：分錄（借 利息費用、貸 應付利息）落 `journal_lines`，下月付款再沖銷。

---

## 六、附件

### 24) `attachments`（附件）
**何時用**：掃描發票、合約影本、驗收單、撥貸通知等。  
**範例**：
```json
{ "ref_table": "ap_bills", "ref_id": 3150, "file_name": "B-2025-0321.pdf", "storage_uri": "s3://bucket/path" }
```
**交叉**：`ref_table + ref_id` 可指向任何單據（例如 `contracts`、`progress_claims`、`journals`）。

## 七、檢視報表（Views）

### `v_project_pnl`（專案損益）
**何時用**：看每個建案收入、成本、淨額（依 `journal_lines` 匯總）。  
**範例**：查詢 `WHERE project_name = '松柏一號'` 看期末損益。  
**交叉**：與 `chart_of_accounts.account_type` 搭配決定收入/成本分類。

---

### `v_ar_aging`（應收帳齡）
**何時用**：依 `due_date` 看當期/逾期 1–30/31–60/…  
**範例**：追蹤業主未收款與保留款尚未釋放。  
**交叉**：金額會扣掉 `ar_settlement_links` 已核銷部分。

## 八、常見交叉流程情境

### 1) 分包進度 → AP → 付款 → 扣繳
1. 現場核准 `progress_claims(分包)` → 產生 `ap_bills`（含保留款 5%）。  
2. 月底付款：建 `cash_bank_txns(out)` → 建立 `ar_ap_settlements(ap_payment)` ＋ `ap_settlement_links`。  
3. 同步建 `withholdings`（1% 扣繳），分錄：借 應付帳款、貸 銀行 ＋ 應付代扣稅。

### 2) 業主請款 → AR → 收款 → 保留款
1. 對業主核准 `progress_claims(主合約)` → 產生 `ar_invoices`（含保留款 %）。  
2. 收款：`cash_bank_txns(in)` → `ar_ap_settlements(ar_receipt)` ＋ `ar_settlement_links`。  
3. 期末釋放保留款：再開傳票（借 應收保留款、貸 工程收入或調整科目），實收時再沖。

### 3) 融資 → 撥貸 → 利息計提 → 還款
1. `loan_drawdowns` → 傳票（借 銀行、貸 借款）。  
2. 月底 `interest_accruals` → 傳票（借 利息費用、貸 應付利息）。  
3. 依 `loan_schedules` 到期還款：`cash_bank_txns(out)` ＋ 分錄（借 應付利息/借款、貸 銀行）。

### 4) 材料採購 → AP → 成本歸集
1. 供應商進項發票 `ap_bills`（鋼筋）。  
2. 過帳 `journal_lines`：借 工程成本-材料（含 `project_id`, `cost_code=C-REBAR`）、借 進項稅額、貸 應付帳款。  
3. `v_project_pnl` 即時看到專案材料成本。

### 5) 銀行對帳
1. 匯入對帳單至 `cash_bank_txns`。  
2. 以金額/日期/對象比對 `journals`，將 `cash_bank_txns.journal_id` 補上，確保一一勾稽。

## 九、實務小叮嚀
- **ref_type/ref_id**（在 `journal_lines`）是追溯來源單的萬用連結，報表或查核很好用。  
- **retaiange（保留款）**：在 `AR/AP` 先計提，釋放時才認列收入或沖減應付（依你的會計政策）。  
- **權限與簽核**：若需簽核流程，可加 `users/roles/approval_flow` 三表，把 `contracts/progress_claims/journals` 納入簽核。  
- **效能索引**：依最常查詢的維度加索引（如 `journal_date`、`project_id`、`party_id`、`voucher_no`）。  
- **多幣別**：若跨幣別頻繁，可把 `amount_foreign` 與 `fx_rate` 前移到 AR/AP、請款等單據層。
